Setup (sirf ek baar)

  1. Firefox me Violentmonkey ya Tampermonkey install karo.
  2. Script copy karo dabao, extension me + → New me paste karke save karo. Paste na dikhe to Script file download karo dabao aur + → New from file se wo file chuno.
  3. Is app ko reload karo. Upar status connected ✅ dikhega.

Kaise chalta hai

  1. Step 4 me 🌐 Use an AI website chuno, site chuno, phir Copy prompt & open site dabao.
  2. AI site par ek chhota panel aayega. Usme jo likha hai bas wahi karo. Jahan dabana ho wahan button blink karega.
  3. Panel ko upar wali patti se pakad kar screen par kahin bhi khiskao. – se chhota karo.
  4. Script purani ho to naya version copy karke Violentmonkey me purani ki jagah paste kar do.

🦊 Sab kuch Firefox me kholne ke liye

Website khud ye force nahi kar sakti, ye phone ki settings se hota hai. Neeche ke steps ek baar kar lo:
  1. Firefox ko default browser banao (Android Settings → Apps → Default apps → Browser app).
  2. Agar Y ai app ki tarah install hai: Settings → Apps → Y ai (ya Chrome) → Open by default me supported links band karo. Ya app uninstall karke Firefox tab me hi use karo.
  3. Firefox → Settings me Open links in apps ko Never karo, taaki Gemini / ChatGPT / Claude ki app na khule.
  4. Menu ke naam phone ke hisaab se thode alag ho sakte hain.
